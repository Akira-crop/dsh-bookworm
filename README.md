# 问书 · Wenshu

微信读书的沉浸式阅读器，装在 DeepSeek Harness 里。

划词就能和 AI 多轮对话，书里的划线、笔记和阅读时长都留在本地。

> 这个插件是从 [灯下 Lamplit](https://github.com/lysforge/dsh-lamplit) 复制出来重做的。
> 只保留微信读书一个来源，把「AI 只是划词挂件」那一半补上。

---

## 为什么另做一个

灯下是个扎实的阅读器，但它的 AI 只做一件事：选中一段 → 解释/补充 → 300 字以内 → 结束。
它自己的 `lib/ai.js` 只有 88 行，天花板写死在那里：单条 user 消息、4000 字截断、收完才返回。

问书在这一层重写了：

| | 灯下 | 问书 |
|---|---|---|
| AI 视野 | 只有你选中的那段 | 可选「这段话 / 这一章 / 整本书」；整章最多 1.2 万字，整书带目录与你已有的笔记 |
| 对话 | 一问一答 | 同一 `sessionId` 下持续追问，最多保留 24 轮，整段自动落成一条笔记 |
| AI 入口 | 遮罩弹出的面板 | 阅读页常驻侧栏，不遮挡正文；另有独立的「对话」页 |
| 输出 | 等 5–30 秒白屏 | SSE 逐字吐出，并把模型思考过程也流出来——推理模型先想一分钟是常态 |
| 正文结构 | 全部是 `<p>` | 标题/引文/列表/分隔线/插图分别渲染 |
| 划线 | 未接 | 读出微信读书的全部划线，按章分组，可跳回正文对应章节 |
| 阅读时长 | 恒为 0（字段名对不上） | 按书统计，首页与统计页都显示；书架卡片显示云端真实时长 |
| 笔记 | 只能新建和删除 | 可编辑正文、可打标签、可按标签筛，**可跨书搜内容**（「那句话在哪本书里」） |
| 全文搜索 | 只搜书名作者 | 搜遍所有已缓存的正文 |
| 同步 | 会清空已缓存正文 | 只更新元数据，正文不动 |
| 交给 Agent | 无 | 7 个 Host Tool，可以直接在对话里问 |

## 功能

### 书架
- 微信读书扫码登录，一键同步整个书架
- **云端进度直接可见**：同步时读出微信读书的百分比、读到第几章、累计时长
- 「继续阅读」优先接你上次在问书里读的书；如果一本都没打开过，就接微信读书进度最深的那本
- 搜索框同时搜书名和**正文**，命中处显示前后文
- 按在读/读完筛选，按最近阅读/加入时间/书名排序

### 阅读
- 四种纸张：跟随宿主 / 纸白 / 米黄 / 夜墨。「跟随宿主」会随 Harness 的明暗模式自动切换
- 衬线或黑体，字号 14–34，行距 1.3–2.6，每行 20–60 字
- 滚动或分页，两端对齐可选
- 目录抽屉、笔记抽屉、划线抽屉
- 键盘：`←`/`k` 上一页、`→`/`j`/空格 下一页、`t` 目录、`n` 笔记、`Esc` 逐层退出
- 自动记录进度，每 5 秒上报一次；只在真的读进去了才写，**不会用 0 覆盖你在微信读书的进度**

### 划词与 AI 对话
选中任意一段，工具条弹出：**解释 / 补充背景 / 记笔记 / 复制**（解释和补充的先后次序可在设置里改）。

右侧会展开一条常驻对话栏，不遮挡正文：

- 顶部是范围切换：**这段话 / 这一章 / 整本书**
  - 「这段话」带上你划中的原文和它前后各 6 段
  - 「这一章」把整章正文（最多 1.2 万字）交给模型，问「这章在讲什么」才有意义
  - 「整本书」带上全书目录和你在这本书里的笔记
- AI 的回答逐字出现，**底部输入框可以连续追问**，最多保留 24 轮
- 等多的时候会显示秒数计时器，并且把模型的思考过程流式显示出来——推理模型常要先想一分钟以上，干等着会以为卡死了
- 生成中随时可以停
- **整段对话自动存成一条笔记**（不会每问一句堆一条），可以在笔记页继续编辑
- 对话栏右上角能「在大页面里继续这段对话」，跳到「对话」页
- 切换范围或换书会自动重置会话（旧会话是上一本书/上一个范围的上下文）

### 对话页
侧栏导航的「对话」是独立的大页面版本：选一本书、问它，或者不指定书随便聊。
从阅读页跳过来会带着当前这本书。

### 笔记
- 按书分组，显示章名和时间
- **正文和标签都能改**——AI 的回答存成笔记后也能继续编辑
- 支持标签云，可按标签筛选、按关键词搜索
- 导出 Markdown：全书或整架

### 统计
- 今日 / 最近七天 / 累计 / 连续天数
- 今日目标可以拖滑杆改（5 分钟到 4 小时），不再是写死的 30 分钟
- 七天柱状图
- **按书时长排行**——能看到这本书你到底读了多少
- 单独的「微信读书累计」卡片，显示云端的真实总时长

### 给 Agent 的工具
装上之后，在 Harness 对话框里可以直接问：

- 「我书架上有哪些书还没读完？」→ `wenshu_shelf`
- 「帮我在所有书里找提到『财政』的地方」→ `wenshu_search`
- 「《置身事内》第三章讲了什么？」→ `wenshu_chapter`
- 「我在这本书里划过哪些线？」→ `wenshu_highlights`
- 「把我的笔记列出来，按标签分类」→ `wenshu_notes`
- 「我好像在哪本书里划过一句关于『习惯』的话，找出来」→ `wenshu_search_notes`（跨所有有笔记的书搜云端划线与想法，不是只搜一本）
- 「我一共有多少条笔记？」→ `wenshu_notes_overview`

`bookId` 参数可以直接传书名，工具会自己解析。

## 安装

```bash
# 在 Harness 里
plugin_manager install_bundle --target <此目录的绝对路径>
```

或者写进 profile 的 bundles 列表。

## 登录微信读书

1. 打开侧栏的「问书」
2. 进「设置」→ 微信读书 → **扫码登录**
3. 二维码用微信扫，手机上确认
4. 登录后自动同步书架

Cookie 存在本地 `~/.dsh/wenshu/state.json`（权限 0600），不上传任何服务器。

微信读书的登录大约一个月会过期，过期后重新扫码即可。也可以用「粘贴 Cookie」手动更新。

## 数据与隐私

全部在 `~/.dsh/wenshu/`：

| 文件 | 内容 |
|---|---|
| `state.json` | 设置、书目、登录凭据、统计数据 |
| `books/<id>.json` | 每本书的目录与已缓存的正文 |
| `notes.json` | 笔记与标签 |
| `cloud-notes/` | 云端划线的本地索引（6 小时后过期重取） |

没有遥测，没有外部上报。删掉这个目录就彻底清理干净。

可以用环境变量 `WENSHU_HOME` 换位置。

### 什么会发出去

问书不设自己的服务器。你的数据只会去两个地方，都是你主动触发：

1. **微信读书**（`weread.qq.com`）——登录、拉书架、拉目录与正文、拉划线想法。走的是你自己的账号。
2. **你 Harness 里配置的模型提供商**——只有在你提问时，问书把「这本书的书名、目录、当前章节、你选中的原文、你的问题」拼进 prompt 发出去。缓存了全文不会自动上传，只有提问范围覆盖到的部分才会。

除此之外没有任何网络请求。

### 什么不会被发出去

- 仓库里没有任何凭据。Cookie 和 API Key 存本机，字段在 `.gitignore` 里
- 仓库里没有截图、没有真实书名、没有账号
- 不收集使用统计

> 如果你要 fork 这个仓库：不要把 `~/.dsh/wenshu/` 里的任何文件复制进仓库，
> 也不要提交截图——截图里通常有你的真实书架、账号尾号和书的正文。

## 边界

说清楚做不到什么：

- **只支持微信读书**。本地文件、GitHub 书库、PDF、EPUB 都去掉了——想读自己的文件请用灯下。
- **进度不回写微信读书**。问书记录的是自己的进度，不会伪造阅读时长写回云端。想双向同步请用 dsh-weread 并打开 `syncProgress`。
- **正文按章拉取**。第一次打开某章需要联网，之后缓存在本地。整本预下载还没做。
- **划线只读**。能看微信读书里的划线，但在问书里新加的笔记不会同步回微信读书。
- **正文解析是正则级的**。微信读书返回的是 XHTML 分片，问书能认出标题、引文、列表、分隔线、插图，但复杂的表格和脚注会退化成普通段落。
- **等你看到第一个字可能要一分钟**。这是模型本身在思考，不是问书卡住。界面上有秒数计时与思考过程可视化；想更快请在 Harness 里换一个不那么爱思考的模型。

## 开发

```bash
node --check client.js
node --check index.js
node --check lib/http-route.js
```

结构：

```
index.js            Host 入口：HTTP 路由 + Agent 工具注册
client.js           全部 UI（React，无 JSX 构建步骤）
lib/
  api.js            service 层：所有业务方法
  http-route.js     Request → service 方法的路由表，含 SSE
  tools.js          7 个 Host Tool
  ai.js             上下文窗口 + 多轮 + 流式（含 reasoning 转发）
  store.js          本地存储，字段名统一、按书时长
  notes.js          笔记与标签
  cloud-notes.js    云端划线/想法的跨书搜索索引
  gateway.js        微信读书官方 Skills 网关客户端
  providers/weread.js   微信读书 provider
  vendor/weread/    微信读书底层：crypto / qr-login / reader / web
```
